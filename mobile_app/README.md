# تطبيق أبو زهرة للإلكترونيات (Flutter - Android & iOS)

تم تحويل مشروع لوحة تحكم وإدارة الحجوزات بالكامل إلى تطبيق هاتف أصلي (Native Mobile App) متعدد المنصات يدعم نظامي **Android** و **iOS** باستخدام **Flutter** و **Dart**، ومتصل مباشرة بنفس قاعدة بيانات **Firebase** الحالية.

---

## 📱 مميزات التطبيق المحول:

1. **الرئيسية (Dashboard):**
   - بطاقات إحصائية للمهام العاجلة (سماعات جديدة، امتحانات جديدة، إثباتات للدفع معلقة، طلبات قيد التنفيذ).
   - ملخص نشاط اليوم التلقائي.
   - سجل الحركة والأنشطة الأحدث مع إمكانية النقر والانتقال المباشر للطلب.

2. **حجوزات السماعات (Headphones):**
   - فلترة سريعة حسب الحالة (قيد المراجعة، تم التواصل، تحت التجهيز، تم الانتهاء، تم التسليم للشحن، تم الاستلام، ملغي).
   - بحث فوري (بالاسم، الهاتف، الجهاز، العنوان).
   - تغيير حالة الحجز من قائمة منبثقة سريعة.
   - اتصال هاتفي مباشر بالعميل ومحادثة واتساب مجهزة برسائل الحجز والفاتورة التلقائية.

3. **حجوزات الامتحانات (Exams):**
   - متابعة الطلاب والشُعب الدراسية.
   - فلترة حسب حالة التأكيد (Pending, Confirmed, Cancelled).
   - تعديل أرقام الجلوس وروابط الامتحانات الفردية.
   - إرسال روابط وتأكيدات الامتحانات عبر واتساب بنقرة واحدة.

4. **مراجعة المدفوعات والإيصالات (Payments):**
   - استعراض إيصالات فودافون كاش وإنستاباي المرفوعة من العملاء.
   - إمكانية تكبير الإيصال والتكبير باللمس (Pinch-to-zoom).
   - رقم محفظة فودافون كاش المحول منها.
   - اعتمـاد الدفع أو رفضه بضغطة زر.

5. **المنتجات والخصومات (Products):**
   - كتالوج المنتجات مع الأسعار والصور والوصف.
   - إضافة وتعديل وحذف المنتجات.
   - تطبيق نسبة خصم عامة على كافة المنتجات أو إلغائها فوراً.

6. **الشُعب الدراسية (Sections):**
   - إدارة الشُعب وروابط الامتحانات والحد الأقصى للطلاب.
   - إحصائية بعدد الطلاب المسجلين بكل شعبة.

7. **الإعدادات والتواصل (Settings):**
   - تعديل رقم الواتساب ورقم فودافون كاش ومبالغ التأمين.
   - تسجيل الخروج من الحساب الإداري.

8. **البحث السريع والتنبيهات:**
   - شريط بحث شامل في كل الحجوزات معاً.
   - شارة حمراء ديناميكية على أيقونة الإشعارات بعدد الحجوزات والإيصالات المعلقة.

## 🚀 كيفية تشغيل التطبيق على جهازك:

### 1. المتطلبات:
- تثبيت [Flutter SDK](https://docs.flutter.dev/get-started/install).
- تثبيت **Android Studio** (لتشغيل محاكي الأندرويد وبناء ملفات APK).
- لجهاز **Mac** (اختياري لبناء نظام iOS و Xcode).

### 2. تثبيت الحزم:
افتح موجه الأوامر (Terminal) داخل مجلد `mobile_app`:
```bash
cd mobile_app
flutter pub get
```

### 3. التشغيل في وضع التطوير (Debug):
- تأكد من توصيل هاتفك عبر كابل USB أو فتح المحاكي (Emulator)، ثم نفّذ:
```bash
flutter run
```

## 📦 بناء النسخة النهائية (Release Build):

### لنظام أندرويد (Android):
- **ملف APK للتثبيت المباشر على أي هاتف أندرويد:**
```bash
flutter build apk --release
```
ستجد الملف الناتج في المسار:
`mobile_app/build/app/outputs/flutter-apk/app-release.apk`

- **ملف App Bundle (AAB) للرفع على متجر Google Play:**
```bash
flutter build appbundle --release
```

### لنظام آيفون (iOS):
- داخل جهاز Mac:
```bash
flutter build ipa
```
أو افتح المجلد داخل Xcode:
```bash
open ios/Runner.xcworkspace
```
ثم قم بعمل Archive والرفع إلى TestFlight أو متجر App Store.
